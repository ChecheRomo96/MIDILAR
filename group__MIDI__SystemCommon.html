Detailed Description

Messages used for system-wide control and transport synchronization in MIDI communication.

System Common Messages include commands like Song Position Pointer and Tuning Request that affect multiple devices in a MIDI network.

Common System Common Messages:

  • System Exclusive
  • Song Position Pointer (0xF2)
  • Song Select (0xF3)
  • Tuning Request (0xF6)
