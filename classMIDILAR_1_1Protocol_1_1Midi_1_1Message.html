Detailed Description

Complete short MIDI 1.0 message in three inline bytes (SPEC-M1-1..4).

Reintroduces the useful builder surface of the historical MidiCore::Message without dynamic storage or exceptions. Not a drop-in replacement: SysEx uses SysExMessage, invalid arguments clear the message instead of clamping, and pitch-bend resolutions have distinct names.

Builder channels are wire indices 0-15 (0 is human channel 1). For explicit numbering use Channel::FromNumber(n).Wire(). Buffer() always includes status: running status belongs to a transport encoder, not this complete message.

MIDILAR::Protocol::Midi::Message msg;
msg.NoteOn(60, 100, 0); // 90 3C 64
const uint8_t* bytes = msg.Buffer(); // valid until msg changes or is destroyed
size_t count = msg.size(); // 3
