Detailed Description

Translates UMP packets into USB MIDI 1.0 event packets (SPEC-USB-2).

Packets are first turned into MIDI 1.0 bytes by a Midi1Encoder (so MIDI 2.0 channel voice is scaled down), then packed into events on the cable equal to the packet's group. System Exclusive is split into three-byte events; bytes that do not fill an event wait, per cable, for the next packet of the same message. Packets without a MIDI 1.0 form produce no events.
