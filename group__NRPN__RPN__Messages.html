Detailed Description

NRPN and RPN messages for extended MIDI parameter control.

These messages allow manufacturers to define custom parameters (NRPN) and handle standard MIDI parameters (RPN). Each Message contains one CC. Send or copy it before rebuilding it; successive builder calls replace its bytes. Select RPN with 101/100 or NRPN with 99/98, then send Data Entry 6 and optional LSB 38.
