Detailed Description

template<typename Storage, uint32_t Bits, uint32_t Midi1Bits, typename Tag>
class MIDILAR::Protocol::ScaledValue< Storage, Bits, Midi1Bits, Tag >

A value at MIDI 2.0 resolution (Bits wide) with a MIDI 1.0 view (Midi1Bits wide), converted with min-center-max scaling (SPEC-MIDI-3).

Every bit pattern is a valid MIDI 2.0 value, so these types have no invalid value. MIDI 1.0 input outside [0, 2^Midi1Bits - 1] is clamped.
