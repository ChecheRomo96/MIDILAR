The eight piece indices and their time-data nibbles.

Piece Component Nibble
0 Frames LSB frame bits 3-0
1 Frames MSB frame bit 4
2 Seconds LSB second bits 3-0
3 Seconds MSB second bits 5-4
4 Minutes LSB minute bits 3-0
5 Minutes MSB minute bits 5-4
6 Hours LSB hour bits 3-0
7 Hours MSB + rate hour bit 4 and rate bits 2-1

TimeCode::QuarterFrame returns the complete data byte; pass just the low nibble to Message::MTC_QuarterFrame(piece, nibble).

#include <MIDILAR_Protocol.h>
using namespace MIDILAR::Protocol;
auto time = TimeCode::From(1, 2, 3, 4, TimeCodeRate::Fps25);
Midi::Message message;
for (uint8_t piece = 0; piece < 8; ++piece) {
uint8_t data = time.QuarterFrame(piece);
message.MTC_QuarterFrame(piece, data & 0x0F);
// Send or copy each message before building the next one.
}
