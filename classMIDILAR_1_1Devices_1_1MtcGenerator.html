Detailed Description

Sends MIDI Time Code, timed by a Foundation::Time::Clock (SPEC-MTC-2).

While running, Update() sends four quarter frames per frame. The eight pieces of one message describe the frame in which piece 0 was sent, so a full time takes two frames. Quarter frames are scheduled from the previous due time with exact rational arithmetic (29.97 is 30000/1001), so the time code does not drift. Locate() sends a full-frame message.
