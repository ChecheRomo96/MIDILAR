Detailed Description

template<typename Tag>
class MIDILAR::Protocol::WireAddress< Tag >

A four-bit wire address in 0-15, the representation shared by MIDI channels and UMP groups (SPEC-MIDI-4).

Built only through FromWire(0-15) or FromNumber(1-16) so the numbering is always explicit. Any other input is the single invalid value, and a valid address is always one a message can carry. Tag keeps channels and groups from being mixed.
