Detailed Description

Follows incoming MIDI Time Code (SPEC-MTC-3).

Every packet passes through. Eight quarter frames in order (pieces 0-7) set Time() to the frame they describe plus two, the frame being played when piece 7 arrives; out-of-order pieces restart the assembly. A full-frame message (F0 7F <device> 01 01 hr mn sc fr F7) sets Time() directly.
