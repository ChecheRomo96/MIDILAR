Detailed Description

SMPTE time transmitted as eight two-byte messages, F1 + data.

Each data byte carries a piece index in bits 6-4 and a data nibble in bits 3-0. Bit 7 is always zero. Four messages are sent per frame, so eight pieces span two frames. MIDI Timing Clock instead expresses musical tempo at 24 pulses per quarter note; it is independent of MTC.

Forward playback sends pieces 0-7, reverse playback in the opposite order. Receiving the full cycle takes time; a receiver must account for that delay. See MIDILAR::Devices::MtcReceiver for the existing implementation.
