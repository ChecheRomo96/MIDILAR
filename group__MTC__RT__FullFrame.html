Locate a complete SMPTE time using ten MIDI bytes.

Full Frame is used for locating, while quarter frames transmit an ongoing position. Universal real-time SysEx (7F) is distinct from the single-byte real-time status range F8-FF.

Bytes Meaning
F0 7F SysEx start, universal real-time
device 00-7F, 7F = all devices
01 01 MTC Full Frame sub-IDs
hr Rate in bits 6-5, hours in bits 4-0
mn sc fr Minutes, seconds, frame number
F7 SysEx end
#include <MIDILAR_Protocol.h>

uint8_t storage[10];

storage, sizeof(storage), time);
