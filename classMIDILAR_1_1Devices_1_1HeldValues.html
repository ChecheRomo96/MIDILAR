Detailed Description

template<typename Value>
class MIDILAR::Devices::HeldValues< Value >

Remembers what a device did with each held note, so a device whose mapping changes while notes sound still releases them (SPEC-DEV-3).

Route() is called with every packet that has a note and the value the device would use now (an output note, a chord shape...). A Note On (MIDI 1.0 velocity 0 excluded) stores that value; a Note Off returns and forgets the stored one; per-note packets return the stored one. Up to Capacity notes are held per device; beyond that, notes use the current value.
