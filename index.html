MIDILAR

MIDILAR is the MIDI layer of the RoModular ecosystem: MIDI 1.0 and MIDI 2.0 protocol, messages, parsing, routing and real-time devices for desktop and embedded targets, built on Foundation (general utilities) and MCC (music theory). MIDI 2.0 Universal MIDI Packets are the internal model; MIDI 1.0 byte streams are translated at the edges.

Note
Version 0.2.0 is the first release of the library rebuilt from scratch, validated on an Arduino Mega 2560.

Modules

  • Core: MIDILAR, MCC and Foundation version information.
  • Protocol: channels, groups, values, UMP packets, MIDI 1.0 and USB MIDI 1.0 translation, MIDI Time Code and MCC pitch conversions.
  • Devices: filters, transforms, scale filter and chord generation, router, MIDI clock, step sequencer and MTC.

Hardware transports are separate libraries built on the Protocol conversions. The rules MIDILAR types follow are collected in the MIDI-Domain Specification.

Dependencies

MIDILAR links Foundation::Foundation (Foundation 1.4 or a newer 1.x release) and MCC::MCC (MCC 0.5.2 or a newer 0.x release). It uses local packages when available and otherwise fetches the pinned releases from GitHub; see Dependencies.
