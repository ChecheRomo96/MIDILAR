Detailed Description

MIDI protocol primitives: channels, groups, masks and data values.

  • Channel and Group store the wire value 0-15, built through FromWire() or FromNumber() (SPEC-MIDI-4).
  • ChannelMask and GroupMask are sets of the sixteen addresses; Omni is ChannelMask::All() (SPEC-MIDI-5).
  • NoteNumber, ControllerNumber and ProgramNumber are 7-bit values (SPEC-MIDI-6).
  • Velocity (16-bit), ControllerValue, PressureValue and PitchBend (32-bit) keep MIDI 2.0 resolution with a MIDI 1.0 view, converted by ScaleUp() and ScaleDown() (SPEC-MIDI-3).
  • ToChromaticIndex(), ToNoteNumber() and ToPitch() convert between note numbers and MCC pitches; 60 is C4 and incoming notes are spelled with an MCC::Key, C major by default (SPEC-MIDI-7).
  • TimeCode is an SMPTE time with its MTC quarter-frame encoding (SPEC-MTC-1).
  • Packet is one Universal MIDI Packet with typed constructors and queries (SPEC-MIDI-16..19).
  • Midi1Parser turns a MIDI 1.0 byte stream into packets, Midi1Encoder turns packets back into bytes and SysExAssembler collects System Exclusive payloads into a caller buffer (SPEC-MIDI-8..15).
  • DecodeUsbMidi1() and UsbMidi1Encoder convert USB MIDI 1.0 event packets (SPEC-USB-1..2). Hardware transports live in separate libraries built on these conversions.

Packet & out )

Translates one USB MIDI 1.0 event packet into a UMP packet (SPEC-USB-1).

An event is four bytes: the cable number (high nibble) and Code Index Number (low nibble), then up to three MIDI bytes. The cable becomes the UMP group. System Exclusive events become 7-bit System Exclusive packets of up to three bytes, marked Start, Continue, End or Complete from the 0xF0 and 0xF7 they carry, so no state is needed. A Note On with velocity 0 becomes a Note Off (SPEC-MIDI-8).

Returns
true and the packet in out, or false for reserved, malformed or empty events.

Scales an unsigned value from sourceBits to targetBits with the MIDI 2.0 min-center-max rule (SPEC-MIDI-3).

Zero stays zero, the source center (1 << (sourceBits - 1)) maps to the target center, and the source maximum maps to the target maximum; values above the center repeat their low bits to fill the extra resolution. Valid for 1 <= sourceBits < targetBits <= 32 and value < (1 << sourceBits); other inputs return 0.
