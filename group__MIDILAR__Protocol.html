Detailed Description

Shared MIDI concepts and separate native/protocol representations.

  • Shared: Channel/ChannelMask, NoteNumber, ControllerNumber, ProgramNumber, SystemStatus, VoiceStatus, TimeCode, scaling and MCC pitch conversion.
  • Midi: native short bytes and caller-buffer SysEx.
  • Midi2: native channel-voice messages and high-resolution values.
  • Ump: packets, groups, format statuses, stream/USB adapters and explicit protocol conversion. UMP carries both MIDI versions.

Native headers under Midi/ and Midi2/ do not include UMP. Devices route Ump::Packet. Ump::Encode adds group/type; DecodeMidi1 and DecodeMidi2 check the representation before exposing native bytes or fields. No implicit conversion changes protocol resolution.

Storage templates and tag types are implementation details under Detail. See the UMP migration section for renamed namespaces and header paths. The MIDI 1.0 protocol guide guide retains the historical MIDI 1.0 topics.

uint32_t sourceBits,
uint32_t targetBits )
noexcept

Scales an unsigned value from sourceBits to targetBits with the MIDI 2.0 min-center-max rule (SPEC-MIDI-3).

Zero stays zero, the source center (1 << (sourceBits - 1)) maps to the target center, and the source maximum maps to the target maximum; values above the center repeat their low bits to fill the extra resolution. Valid for 1 <= sourceBits < targetBits <= 32 and value < (1 << sourceBits); other inputs return 0.
