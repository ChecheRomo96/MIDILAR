Detailed Description

An SMPTE time hh:mm:ss:ff at an MTC frame rate (SPEC-MTC-1).

Hours run 0-23. At 29.97 drop-frame, frame numbers 0 and 1 do not exist at the start of each minute except minutes 0, 10, 20, 30, 40 and 50, so the numbering keeps up with real time. Invalid input produces the invalid time code (SPEC-RT-3).
