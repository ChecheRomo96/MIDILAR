Detailed Description

template<typename Tag>
class MIDILAR::Protocol::DataValue< Tag >

A 7-bit data value in [0, 127] (SPEC-MIDI-6).

Any other input is the single invalid value. Tag keeps note, controller and program numbers from being mixed.
